## 🚀 Projetos em destaque

### Pipeline de Dados — Copa do Mundo 2026
Pipeline de dados de ponta a ponta: extração de 6 fontes públicas (ESPN API,
football-data.org, FBref, StatsBomb, Open-Meteo), transformação com modelagem
dimensional em dbt (staging → marts com testes de qualidade), armazenamento em
PostgreSQL e sincronização para Neon (cloud). Dashboard interativo de 11 páginas
no Looker Studio com análise por partida, jogador, seleção, goleiro e clima.

🔗 Repositório: [world-cup-2026-data-pipeline](https://github.com/gustavohenriqq/world-cup-2026-data-pipeline)
📊 Dashboard ao vivo: [Looker Studio](https://datastudio.google.com/reporting/5de5a394-bffa-4065-900f-eba800e4ee9a)

---

### Dashboard de Controle de Devoluções — Power BI
Solução completa de BI desenvolvida na AMBEV S.A e em uso real na operação da
unidade. ETL de mais de 800 registros, modelagem relacional, mais de 30 medidas
DAX e dashboard interativo com atualização automática via SharePoint.

🔒 Repositório privado por confidencialidade corporativa

---

### Workflow Approval Engine
Plataforma full stack para automação de fluxos de aprovação corporativos com
regras de negócio complexas: designer visual de fluxos, autenticação JWT, controle
de acesso por perfil (RBAC), cache com Redis, dashboard com KPIs e SLA, auditoria
completa, Docker e testes com Jest.

🔗 Repositório: [workflow-final](https://github.com/gustavohenriqq/workflow-final)

---

### CodeSentinel
API REST para análise e monitoramento de métricas de qualidade de código-fonte:
Java com Spring Boot, autenticação JWT, persistência em PostgreSQL, testes com
JUnit e arquitetura em camadas com Clean Code.

🔗 Repositório: [CodeSentinel](https://github.com/gustavohenriqq/CodeSentinel)
