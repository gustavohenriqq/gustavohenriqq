## 🚀 Projetos em destaque

### Dashboard de Controle de Devoluções — Power BI
Solução completa de BI desenvolvida na AMBEV S.A e em uso real na operação da unidade:

- Pipeline ETL com mais de 800 registros via Power Query
- Migração e integração de dados SAP ECC → SAP S/4HANA
- Modelagem relacional com mais de 30 medidas DAX
- Dashboard interativo com 3 páginas e atualização automática via SharePoint
- Eliminou processo de análise 100% manual

🔗 Repositório: [dashboard-devolucoes-powerbi](https://github.com/gustavohenriqq/dashboard-devolucoes-powerbi)

---

### Workflow Approval Engine
Plataforma full stack para automação de fluxos de aprovação corporativos:

- Designer visual de fluxos interativos
- Autenticação JWT e controle de acesso por perfil (RBAC)
- Cache e filas com Redis
- Dashboard com KPIs e SLA
- Trilha de auditoria completa e versionamento
- Containerização com Docker e testes com Jest

🔗 Repositório: [workflow-final](https://github.com/gustavohenriqq/workflow-final)

---

### CodeSentinel
API REST para análise e monitoramento de métricas de qualidade de código-fonte:

- Back-end em Java com Spring Boot
- Autenticação JWT e persistência em PostgreSQL
- Testes unitários com JUnit
- Arquitetura em camadas com Clean Code

🔗 Repositório: [CodeSentinel](https://github.com/gustavohenriqq/CodeSentinel)
